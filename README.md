# Gym Scraper

This project scrapes gym data from Google Maps using Selenium and undetected-chromedriver.

## Usage
- Place your province/city CSVs in `province_list/`.
- Run `create_results_structure.py` to generate the results folder structure.
- Add your proxies to `proxies.txt`.
- Run `main.py` to start scraping.

## Requirements
- Python 3.7+
- See `requirements.txt`
